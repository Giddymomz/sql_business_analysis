# SQL Business Analysis

**Question:** Who are our best customers, which products sell most, and where is revenue coming from?

**Tools:** SQL (SQLite / MySQL), Python for verification

## Database

- `customers` - Customer ID, Name, Region
- `orders` - Order ID, Customer ID, Product, Amount, Date

## Key Findings

1.  **Top Customer:** Jane Wanjiru - Highest total spend
2.  **Top Product:** Electronics - Highest revenue
3.  **Top Region:** Nairobi - Most orders
4.  **Insight:** Focus retention on top 5 customers - they drive 60%+ of revenue

## Files

- `customers.csv` - Customer table
- `orders.csv` - Orders table
- `analysis.sql` - All SQL queries used
